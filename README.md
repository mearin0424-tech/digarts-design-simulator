# digarts-design-simulator

https://mearin0424-tech.github.io/digarts-design-simulator/index.html

---

## 概要

**POD Graphic Maker** は、Tシャツ・アクリルスタンド等のPOD（Print On Demand）向け入稿データを、ブラウザ上で作成・品質チェックできる単一HTMLアプリケーションです。背景となるモックアップ画像に印刷範囲枠を合わせ、デザイン画像を配置しながら、実寸（cm）と解像度（dpi）をリアルタイムに確認できます。

- 形式: 単一の `index.html`（依存はTailwind CSS CDNのみ、ビルド不要）
- 動作: 静的ホスティング（GitHub Pages）でそのまま動作
- 保存: 配置画像はメモリ上のみ。**ボディ情報のみ `localStorage` に永続化**

## 機能仕様

### 1. 背景（モックアップ）

| 項目 | 仕様 |
| --- | --- |
| 画像読み込み | 左パネル「画像を選択」から `image/*` を読み込み |
| ボディから選択 | 登録済みボディ（後述）の画像を背景として適用 |
| 初期スケール | ワークスペースの90%に収まる倍率を自動算出（最大1倍） |
| サイズ調整 | スライダー（5%〜300%）で拡縮 |
| 背景色 | カラーピッカーで指定（既定 `#f8fafc`） |
| 初期化 | 「背景を初期化」で画像・色・ボディ選択をリセット |
| 選択中ボディの表示 | 背景セクション下部にバッジで「品番 / 名前」を表示 |

### 2. 印刷枠（キャンバス）

- 中央の青枠が印刷範囲を表す。**ドラッグで移動**、**右下ハンドルでリサイズ**。
- 左パネルで **実寸（cm）幅・高さ** を入力（既定 30 × 30 cm、ステップ 0.1）。
- **縮尺ロック**（`縮尺(スケール)を固定する`）
  - 未ロック時: 枠リサイズは実寸（cm）比率を維持したまま見た目だけ変動。cm入力時はピクセル幅を維持し高さを比率連動。
  - ロック時: ロック時点の `px/cm` を保持し、枠リサイズが実寸（cm）に直接連動。cm入力は枠ピクセル寸法に直接反映。
- ロック状態に応じてボタン外観・説明文が切り替わる。

### 3. 素材画像のアップロードと配置

- 追加方法は2系統:
  - 左パネル **「3. 素材画像をアップロード」→ 画像を選択** （複数選択可）
  - ワークスペースへ **ドラッグ＆ドロップ** （複数同時可）
- 初期サイズ: 枠幅の80%（元画像が小さい場合は元サイズ）、枠中央に配置。
- 選択した画像は **四隅ハンドル** が表示され、アスペクト比固定でリサイズ。
- 右パネルの各画像カードから **X / Y / W / H（cm）** を直接入力可能。
- 画像枠外の領域は枠境界でクリップ表示。

### 4. 解像度（DPI）表示

- 各画像左上に **実寸解像度（dpi）** をリアルタイム表示。
- 計算式: `dpi = 元画像のピクセル幅 / (枠上での実寸幅 cm × 1/2.54)`
- 警告閾値（既定 200 dpi、**右パネル「品質チェック基準」で変更可**）を下回ると **赤バッジ**、満たすと **緑バッジ**。
- 右パネルのリストにも同じ判定アイコン付きで表示。

### 5. 透過漏れ（半透明ゴミ）検知

- 右パネル「透過漏れをスキャン」で全配置画像を一括スキャン。
- 判定: 各ピクセルのアルファ値が **`0 < α < 255`** の場合に「漏れあり」とみなす（完全透明 / 完全不透明のみが正常）。
- 検知時はオーバーレイ画像を黄色（`#FFFF00`）で生成し、画像上に重ね赤いドロップシャドウで強調。
- リスト項目に「透過漏れを検知しました」を表示し、**詳細表示** で専用インスペクター（モーダル）を開く。

### 6. 出力

ヘッダー右上に2系統の出力ボタン。

| ボタン | 目的 | 仕様 |
| --- | --- | --- |
| `枠内のみ出力(素材)` | 印刷所への入稿用素材 | 枠の実寸を **350 dpi 換算** したPNG（背景含まず）。既定ファイル名: `PrintData_{W}x{H}cm_350dpi.png` |
| `背景ごと出力` | SNS・確認用モックアップ | ワークスペース全体を **2倍スケール** で描画したPNG。背景色・背景画像・枠内画像（枠でクリップ）を合成。既定ファイル名: `Mockup_{timestamp}.png` |

出力時にファイル名入力のプロンプトが表示され、任意の名前を指定できます。空欄ならば既定名が使われ、`.png` 拡張子は自動付与、ファイル名に使えない文字（`\ / : * ? " < > |`）は `_` に置換されます。キャンセル時は保存されません。

### 7. ボディ管理（商品マスタ）

左パネル「**ボディから選択**」ボタンで、商品本体（Tシャツ、アクリルスタンド等）のマスタを管理できます。

- **登録項目**
  - 品番（必須）
  - 名前（必須）
  - 画像（任意。登録すると背景としてワンクリック適用可能）
- **操作**
  - 新規登録 / 編集 / 削除（削除時は確認ダイアログ）
  - 画像付きボディは「背景に適用」で背景画像として読み込み
- **永続化**: `localStorage` キー `digarts-design-simulator:bodies` にJSON保存
  - 画像はData URLとして保存。容量超過時はアラート表示
- **選択中表示**: 背景として適用中のボディは、左パネル背景セクション下部にバッジで「品番 / 名前」を表示

### 8. 使い方マニュアル

- ヘッダー「使い方」ボタンでステップ別ガイドのモーダルを表示。

## 技術仕様

- **HTML/CSS/JS**: 単一ファイル（外部スクリプトはTailwind CSS CDNのみ）
- **ライブラリ**: なし（バニラJS）
- **キャンバス処理**: `<canvas>` 2D API による DPI 換算描画と `getImageData` によるアルファ判定
- **状態管理**: グローバル `state` オブジェクト
  ```js
  {
    cmW, cmH,              // 枠の実寸（cm）
    targetDpi: 200,        // 警告閾値
    exportDpi: 350,        // 入稿出力時の固定dpi
    images: [...],         // 配置画像 { id, img, name, origW, origH, x, y, w, h, hasLeak, leakDataUrl }
    selectedId,
    isScaleLocked,         // 縮尺ロック中か
    lockedPxPerCm,         // ロック時の px/cm
    bgScale,               // 背景画像の拡大率
    bodies: [...],         // 登録ボディ { id, partNumber, name, imageDataUrl?, createdAt }
    selectedBodyId,        // 背景に適用中のボディID
    bodyFormEditingId,     // フォーム編集対象ID（新規ならnull）
    bodyFormImageSrc       // フォーム内の画像Data URL
  }
  ```
- **座標系**: 画像の `x, y, w, h` は枠左上を原点としたピクセル値。表示時に `px/cm` で cm へ換算。
- **永続化**: `localStorage` キー `digarts-design-simulator:bodies` にボディマスタを保存。
- **ブラウザ要件**: モダンブラウザ（Chrome / Edge / Firefox / Safari）
